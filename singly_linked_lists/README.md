# Singly Linked Lists in C

![Linked List](https://upload.wikimedia.org/wikipedia/commons/6/6d/Singly-linked-list.svg)

Este repositorio contiene implementaciones y ejemplos de listas enlazadas simples (Singly Linked Lists) en C. Las listas enlazadas simples son una estructura de datos fundamental en la programación, donde cada elemento (nodo) contiene un valor y un puntero al siguiente nodo en la secuencia.

## Descripción

Una lista enlazada simple es una colección de nodos donde cada nodo contiene dos partes:
1. Un dato (de tipo entero en este ejemplo).
2. Un puntero al siguiente nodo en la lista.

El último nodo en una lista enlazada simple apunta a `NULL`, indicando el final de la lista.
