EXIT (3)

--Propósito--
exit se utiliza para terminar un programa y realizar una limpieza adecuada de los recursos utilizados. Es especialmente útil cuando se necesita finalizar el programa en respuesta a un error o a una condición específica.

--Sintaxis--

void exit(int status);

--Parámetros--
status: Un valor entero que indica el estado de finalización del programa. Generalmente, un valor de 0 indica que el programa terminó con éxito, mientras que cualquier otro valor indica un error.

--Retorno--
exit no devuelve ningún valor ya que termina el programa.
